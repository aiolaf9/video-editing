# Font

Font bawaan (semuanya berlisensi SIL Open Font License, bebas dipakai komersial; lisensi ada di file `OFL-*.txt`):

- **Poppins** (SemiBold, Bold, ExtraBold): teks animasi dan subtitle
- **Anton**, **Bebas Neue**: judul dan kata kunci besar

Ingin font lain? Taruh file `.ttf` / `.otf` di folder ini (misalnya dari https://fonts.google.com),
lalu pilih nama fontnya di panel **Subtitle**.
